# THE TERWILLIGER ALGEBRA OF DIGRAPHS I <br> —HAMMING DIGRAPH $H^{*}(d, 3)$ — 

TSUYOSHI MIEZAKI, HIROSHI SUZUKI, AND KEISUKE UCHIDA


#### Abstract

In the present paper, we define the Terwilliger algebra of digraphs. Then, we determine the irreducible modules of the Terwilliger algebra of a Hamming digraph $H^{*}(d, 3)$. As is well known, the representation of the Terwilliger algebra of a binary Hamming graph $H(d, 2)$ is closely related to that of the Lie algebra $s l_{2}(\mathbb{C})$. We show that in the case of $H^{*}(d, 3)$, it is related to that of the Lie algebra $s l_{3}(\mathbb{C})$. We also identify the Terwilliger algebra of $H^{*}(d, 3)$ as the $d$ symmetric tensor algebra of $\operatorname{Mat}_{3}(\mathbb{C})$. Key Words: Terwilliger algebras, Hamming digraph. 2020 Mathematics Subject Classification. Primary 05C25; Secondary 17B10, 05 E 30 .


## 1. InTRODUCTION

Definition 1.1. Let $N=\left\{a_{1}, a_{2}, \ldots, a_{n}\right\}$. The Hamming graph $H(d, n)$ or more specifically, the Hamming graph of diameter $d$ on the set $N$, $H(d, N)$ is defined by $X$, the set of vertices, and $\tilde{E}$, the set of edges.

$$
\begin{aligned}
& X=\left\{\left(x_{1}, \ldots, x_{d}\right) \mid \text { for all } i, x_{i} \in N\right\} \\
& \tilde{E}=\left\{\{x, y\} \mid \text { exactly } 1 \text { coordinate } i, x_{i} \neq y_{i}\right\} \subseteq X \times X
\end{aligned}
$$

We use a trivial direction on each coordinate, $0 \rightarrow 1 \rightarrow 2 \rightarrow 0$ if $N=\mathbb{F}_{3}=G F(3)$.

Definition 1.2. The directed graph $H^{*}(d, 3)$ is defined by $X$, the set of vertices, and $E$, the set of arcs.

$$
\begin{aligned}
& X=\left\{\left(x_{1}, \ldots, x_{d}\right) \mid \text { for all } i, x_{i} \in \mathbb{F}_{3}\right\} \\
& E=\left\{(x, y) \mid \text { exactly } 1 \text { coordinate } i, x_{i}+1=y_{i}\right\} \subseteq X \times X
\end{aligned}
$$

Let $\Gamma=(X, E)$ be $H^{*}(d, 3)$ and $\operatorname{Mat}_{X}(\mathbb{C})$ the matrix algebra whose rows and columns are indexed by the elements of $X$.The adjacency matrix of $H^{*}(d, 3), A \in \operatorname{Mat}_{X}(\mathbb{C})$ is defined by the following.

$$
(A)_{i j}= \begin{cases}1 & \text { if there exists an arc from } i \text { to } j \\ 0 & \text { otherwise }\end{cases}
$$

For $x, y$ in $X, \partial(x, y)$ denotes the distance between $x$ and $y$, i.e., the smallest number of arcs connecting from $x$ to $y$. We also define the twoway distance $\tilde{\partial}(x, y)=(\partial(x, y), \partial(y, x))$, and $\Delta$, the set of all two-way distances;

$$
\Delta=\{\tilde{\partial}(x, y) \mid x, y \in X\}
$$

We fix a base vertex $x=(0,0, \ldots, 0) \in X$. Let $V=\mathbb{C}^{|X|}$ be the vector space over the complex number field $\mathbb{C}$ whose coordinates are indexed by the elements of $X$. For $y \in X, \hat{y}$ denotes the unit vector in $V$. Let

$$
X_{i, j}=\{y \mid \partial(x, y)=i, \partial(y, x)=j\}
$$

If there are $s$ ones and $t$ twos, and therefore $r=d-s-t$ zeros, then $\partial(x, y)=s+2 t, \partial(y, x)=2 s+t$. If $\tilde{\partial}(x, y)=(i, j)$, then $s=(2 j-i) / 3$, and $t=(2 i-j) / 3$.

For $(i, j) \in \Delta, E_{i, j}^{*} \in \operatorname{Mat}_{X}(\mathbb{C})$ denotes a diagonal matrix such that

$$
E_{i, j}^{*}(z, z)=1, \text { if } \tilde{\partial}(x, z)=(i, j)
$$

and the zero matrix of the same size if $(i, j) \notin \Delta$. Then,

$$
E_{i, j}^{*} \mathbf{1}=\{\sum \hat{y} \mid y \in X, \partial(x, y)=i, \partial(y, x)=j\}
$$

We also write

$$
X_{[s, t]}=\{y \mid \text { there are } s \text { ones and } t \text { twos }\}=X_{s+2 t, 2 s+t}
$$

If a vector $\boldsymbol{v} \in V$ is a linear combination of the unit vectors corresponding to the elements in $X_{[s, t]}$, i.e., if $E_{[s, t]}^{*} \boldsymbol{v}=\boldsymbol{v}$ with $r=d-s-t$, we write

$$
r(\boldsymbol{v})=r, s(\boldsymbol{v})=s, \text { and } t(\boldsymbol{v})=t
$$

Hence, if $E_{[s, t]}^{*} \boldsymbol{v}=\boldsymbol{v}$, we write type $(\boldsymbol{v})=(r(\boldsymbol{v}), s(\boldsymbol{v}), t(\boldsymbol{v}))$, and call it the type of $\boldsymbol{v}$. We set

$$
E_{i, j}^{*}=E_{[(2 j-i) / 3,(2 i-j) / 3]}^{*}, \text { and } E_{[s, t]}^{*}=E_{s+2 t, 2 s+t}^{*}
$$

Let $X_{i, j}=X_{[s, t]}$, where $t=(2 i-j) / 3$, and $s=(2 j-i) / 3$. Then,

$$
\left|X_{[s, t]}\right|=\binom{d}{s+t}\binom{s+t}{s}=\binom{d}{s}\binom{d-s}{t}
$$Definition 1.3. The Terwilliger algebra $\mathcal{T}(x)$ of $H^{*}(d, 3)$ with respect to a base vertex $x$ is a $\mathbb{C}$-algebra generated by $A, A^{\top}$ and $E_{i, j}^{*}$ for $(i, j) \in \Delta$, and the vector space $V=\mathbb{C}^{|X|}$ is called the standard module of $\mathcal{T}(x)$. We also write $\mathcal{T}\left(H^{*}(d, 3)\right)$ to specify the digraph.
Theorem 1.4. Let $\mathcal{T}(x)$ be the Terwilliger algebra of $H^{*}(d, 3)$ with respect to a base vertex $x$. Then,

$$
\mathcal{T}(x) \simeq \operatorname{Sym}^{(d)}\left(\operatorname{Mat}_{3}(\mathbb{C})\right)
$$

Moreover,

$$
\mathcal{T}(x) \simeq \operatorname{Sym}^{(d)}\left(\operatorname{Mat}_{3}(\mathbb{C})\right) \simeq \bigoplus_{n \in \Lambda} \operatorname{Mat}_{n}(\mathbb{C})
$$

where

$$
\begin{aligned}
& \Lambda=\left\{\left.\frac{1}{2}(d-3 \ell-2 m+1)(m+1)(d-3 \ell-m+2)\right\rvert\,\right. \\
& 0 \leq \ell \leq\left[\frac{d}{3}\right], 0 \leq m \leq\left[\frac{d-3 \ell}{2}\right]\right\}
\end{aligned}
$$

We also describe the irreducible $\mathcal{T}(x)$ modules in the standard module. See sections 3 and 4.

This paper is organized as follows. In Section 2, we define several matrices derived from $H^{*}(d, 3)$ and establish their connection with the Lie algebra $s l_{3}(\mathbb{C})$. In Sections 3 and 4, we present the irreducible representations of the Terwilliger algebra of $\mathcal{T}\left(s l_{3}(\mathbb{C})\right)$. Finally, in Section 5 , we provide a proof of Theorem 1.4.

Lemma 2.1. We have the following.
(i) $A=R_{1}+R_{2}+L_{3}$ and $A^{\top}=L_{1}+L_{2}+R_{3}$.
(ii) Let $\tilde{A}=A+A^{\top}$. Then $\tilde{A}$ is the adjacency matrix of $H(d, 3)$.
(iii) $\tilde{R}=R_{1}+R_{3}$ is the raising operator, $\tilde{F}=R_{2}+L_{2}$ the flat operator, and $\tilde{L}=L_{1}+L_{3}$ the lowering operator of $H(d, 3)$.

Proof. Straightforward. See [2, Chapter 30] for the raising, flat, and lowering operators.

Lemma 2.2. The following hold.
(i) $\left[L_{1}, R_{1}\right]=H_{1},\left[H_{1}, L_{1}\right]=2 L_{1}$, and $\left[H_{1}, R_{1}\right]=-2 R_{1}$.
(ii) $\left[L_{2}, R_{2}\right]=H_{2},\left[H_{2}, L_{2}\right]=2 L_{2}$, and $\left[H_{2}, R_{2}\right]=-2 R_{2}$.

$$
\begin{aligned}
{\left[L_{1}, R_{1}\right] \hat{y} } & =\left(L_{1} R_{1}-R_{1} L_{1}\right) \hat{y} \\

$$
\begin{aligned}

\end{aligned}
$$

Hence, $\left[H_{1}, L_{1}\right]=2 L_{1}$.
$\left[H_{1}, R_{1}\right]=\left[H_{1}^{\top}, L_{1}^{\top}\right]=H_{1}^{\top} L_{1}^{\top}-L_{1}^{\top} H_{1}^{\top}=\left[L_{1}, H_{1}\right]^{\top}=-\left[H_{1}, L_{1}\right]^{\top}=-2 R_{1}$.
(ii) and (iii) are similar.

(ii) $\left[L_{1}, L_{2}\right]=L_{3}$.
(iii) $\left[L_{1}, R_{2}\right]=O$.
